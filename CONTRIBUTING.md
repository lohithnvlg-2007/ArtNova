# Contributing to ArtNova

Thank you for your interest in the ArtNova project.

ArtNova is an artwork registration and authenticity verification system integrating a web platform, Supabase cloud storage, and a Raspberry Pi device for local data backup and synchronization.

## How to Contribute

1. Review the project README before making changes.
2. Create a separate branch for significant changes.
3. Test all changes before submitting them.
4. Describe your changes clearly in your commit messages.
5. Do not submit passwords, API keys, private credentials, or personal artist data.

## Development Guidelines

* Preserve the existing Raspberry Pi registration functionality.
* Test Supabase database operations and synchronization carefully.
* Protect artist and owner information.
* Verify that backup and recovery procedures work before production use.
* Test changes to data deletion and synchronization to prevent accidental data loss.

## Reporting Issues

Report bugs and feature suggestions through the GitHub Issues section.

Include clear steps to reproduce bugs and describe the expected behaviour.

## Code of Conduct

Be respectful, constructive, and professional when discussing the project or suggesting changes.

## Project Maintenance

Changes affecting security, authentication, database structure, or data synchronization should be reviewed and tested by the project administrator before deployment.
